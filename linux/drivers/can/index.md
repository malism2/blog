# CAN驱动开发

CAN（Controller Area Network）是一种广泛用于工业自动化、汽车电子等领域的串行总线标准。本章节将详细介绍Linux内核中CAN驱动的开发方法、核心概念和实现细节。

## CAN驱动的基本概念

CAN驱动开发需要了解以下基本概念：

1. **CAN总线**：一种多主串行总线，支持实时通信
2. **CAN控制器**：负责实现CAN协议的硬件设备
3. **CAN帧**：CAN总线中传输的基本数据单元
4. **CAN网络设备**：Linux内核中表示CAN控制器的网络设备
5. **SocketCAN**：Linux内核中用于CAN通信的套接字接口

## 为什么学习CAN驱动开发？

- CAN总线在汽车电子、工业自动化等领域广泛应用
- SocketCAN提供了便捷的CAN通信接口
- 掌握CAN驱动开发可以扩展Linux系统支持的CAN设备
- 实时系统开发的重要实践
