# 自然语言处理 (NLP) 基础：词嵌入、循环神经网络与注意力机制入门

**作者：Manus AI**

## 摘要

自然语言处理 (NLP) 是 AI 领域中研究人与计算机之间交互的关键技术。大模型 (LLM) 正是 NLP 发展的集大成者。对于初学者而言，理解 NLP 的三大核心概念——**词嵌入 (Word Embedding)**、**循环神经网络 (RNN)** 和 **注意力机制 (Attention)**，是掌握 LLM 原理的基础。本文将以入门级视角，解释这些概念的工作原理和重要性。

## 1. 词嵌入 (Word Embedding)：让计算机理解语义

计算机无法直接处理文本，必须将词语转换为数值形式。词嵌入就是将词语映射到低维向量空间的技术。

### 1.1 独热编码的局限性

传统的**独热编码 (One-Hot Encoding)** 将每个词表示为一个长向量，向量中只有一个位置为 1，其余为 0。
-   **问题**: 向量维度过高，且无法表达词语之间的**语义关系**。例如，“国王”和“女王”的独热编码向量是完全正交的，无法体现它们之间的相似性。

### 1.2 词嵌入的优势

词嵌入将词语表示为**稠密 (Dense)** 的低维向量，向量中的每个维度都代表了词语的某种潜在特征。

-   **核心**: 语义相似的词语在向量空间中的距离也更近。
-   **经典模型**: **Word2Vec**（包括 CBOW 和 Skip-gram 模型）和 **GloVe** 是最早实现这一目标的模型。
-   **应用**: 词嵌入是所有现代 NLP 任务（如机器翻译、情感分析）的输入基础。

## 2. 循环神经网络 (Recurrent Neural Network, RNN)

自然语言具有**序列性**，即一个词的含义依赖于它前面的词。RNN 是专门设计来处理序列数据的神经网络。

### 2.1 RNN 的核心结构

RNN 的核心在于其**循环结构**：它在处理序列中的当前元素时，会利用前一个时间步的**隐藏状态 (Hidden State)**，从而实现对历史信息的记忆。

-   **优势**: 能够捕捉序列中的**长期依赖关系**。
-   **局限性**: 随着序列长度增加，梯度在反向传播时容易出现**梯度消失**或**梯度爆炸**，导致模型难以学习到非常遥远的依赖关系。

### 2.2 进阶模型：LSTM 与 GRU

为了解决 RNN 的局限性，研究人员提出了 **长短期记忆网络 (LSTM)** 和 **门控循环单元 (GRU)**。

-   **核心**: 它们引入了**门控机制 (Gating Mechanism)**（如输入门、遗忘门、输出门），来选择性地记忆或遗忘信息，从而更有效地控制信息流，解决了长期依赖问题。

## 3. 注意力机制 (Attention Mechanism)

注意力机制是现代 NLP 的核心创新，也是 Transformer 和 LLM 的基石。

### 3.1 为什么需要注意力？

在处理长序列时，即使是 LSTM/GRU，也难以记住所有信息。注意力机制模仿人类的注意力，允许模型在处理当前信息时，**动态地关注**输入序列中**最相关**的部分。

### 3.2 注意力机制的工作原理

1.  **查询 (Query)**: 当前要处理的信息。
2.  **键 (Key)**: 输入序列中所有元素的信息。
3.  **值 (Value)**: 输入序列中所有元素的实际内容。

模型通过计算 Query 和 Key 之间的**相似度**，得到一个**权重分布**（即注意力分数），然后用这个权重分布对 Value 进行加权求和，得到一个包含**上下文信息**的输出。

### 3.3 自注意力 (Self-Attention)

自注意力是 Transformer 架构的核心，它允许模型在处理序列中的一个词时，同时关注**序列中的所有其他词**，从而捕捉到词语之间的**内部依赖关系**。

## 4. 总结

-   **词嵌入**解决了文本的数值化表示问题，并赋予了词语语义信息。
-   **循环神经网络**解决了序列数据的处理问题，通过循环结构实现记忆。
-   **注意力机制**解决了长序列的依赖问题，通过动态加权实现对关键信息的聚焦。

这三大基础是理解 Transformer 架构和 LLM（如 GPT、BERT）工作原理的必经之路。
